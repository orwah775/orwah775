# أرشيف عجبان

أرشيف بحثي يجمع المواد والوثائق والمصادر المتعلقة بعجبان – النادرة – إب.

## محتويات الأرشيف

سيتم تنظيم الأرشيف في الأقسام التالية:

- الكتاب
- الوثائق
- المخطوطات
- المصادر
- الصور
- الخرائط

## ملاحظات التوثيق

سيتم التفريق بين المعلومات الموثقة بالمصادر، والروايات المحلية، والمعلومات التي تحتاج إلى مزيد من التحقق.
